# まいにち計算

日めくりカレンダーをめくるように1問ずつ解く、高齢の方向けのスマートフォン用ゲームです。

- **計算**：足し算・引き算・掛け算（九九）・おまかせ。むずかしさは「やさしい／ふつう／むずかしい（3けた）」
- **4択クイズ**：豆知識つき。ジャンルは「おまかせ・ひっかけ問題・なぞなぞ・ことわざ／漢字・季節／くらし・歴史／地理・生きもの／食べもの」
- **ごちゃまぜ**：計算5問とクイズ5問がまざって出ます

1回10問、制限時間なし。大きな文字とボタンで操作できます。

## 遊び方

`index.html` 1つだけで動きます。サーバーやインストールは不要です。

## 保存するデータ

「今日の正解数」と「前回選んだ設定」だけを、使っている端末のブラウザ内（localStorage）に保存します。外部には送りません。

## セキュリティ

- `index.html` には Content-Security-Policy を設定しています。読み込めるのは Google Fonts だけで、それ以外の外部への通信はすべてブロックされます。
- ページ内のスクリプトは、ハッシュ値（`script-src 'sha256-…'`）で許可しています。

> **注意：** `<script>` の中身を1文字でも書きかえると、ハッシュ値が合わなくなり、ゲームが動かなくなります。
> 中身を変えたときは、新しいハッシュ値を計算して `<meta http-equiv="Content-Security-Policy">` の `sha256-` の部分を書きかえてください。

## 時事問題の入れかえ

`index.html` の `const JIJI = [...]` に、2026年秋の時事問題が入っています。
時間がたつと古くなるので、1〜2か月に一度入れかえてください。
入れかえたら `JIJI_WHEN`（ラベルの「2026年秋」）も変えてください。
